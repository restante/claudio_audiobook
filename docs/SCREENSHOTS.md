# Screenshots to capture (real ones only)

The README has marked slots for these. Capture them from a real run, then replace the `<!-- ... -->` comments
with `![alt](docs/img/<file>)`. Keep each PNG under ~300 KB, width 1400 px, light mode.

| # | File | What to show | Notes |
|---|---|---|---|
| 1 | `docs/img/hero.gif` | Claude Desktop or Code: the prompt "create a python course audiobook…", chapter list, "done, saved to ~/Audiobooks/…" | 10–15 s, sped up while rendering. Top of the README, so it carries the most weight. |
| 2 | `docs/img/desktop-chat.png` | Claude Desktop with the extension active and the finished-job message | Hide your account name and any private chats. |
| 3 | `docs/img/chapters.png` | The `.m4b` open in Apple Books / Podcasts / VLC with the chapter list visible | Proves the chapter marks. |
| 4 | `docs/img/settings.png` | Desktop → Extensions → claudio-audiobook settings (voice, speed, folder) | Optional. |

Use a neutral topic (the Python course), not private study material. For a social-preview image, export a
1280×640 PNG of shot 1 and set it in repo Settings → Social preview.
